# Документирование Discovery

- Пользовательская документация лежит в `docs/` этого репозитория. Карта разделов: `docs/installation.md`, `configuration.md`, `api-reference.md`, `troubleshooting.md`, `features.md`, `docs/features/*.md`, скриншоты — `docs/images/`. Открывай только относящиеся к задаче страницы.
- Описывай текущее пользовательское поведение, настройку, ограничения и проверяемый пример. Не публикуй запланированные протоколы как реализованные. Факты сверяй с кодом и результатами проверки.
- Корневой `QUICKSTART.md` должен работать как самостоятельная инструкция в пакете: первый запуск, credentials, сохраняемое storage, логи. Не делай обязательными ссылки на файлы, отсутствующие в установленном пакете.
- При изменении установки синхронизируй `QUICKSTART.md`, `docs/installation.md` и при необходимости `README.md`; для API/функции обновляй адресный раздел. Не копируй всю документацию продукта в инструкции ИИ.
- Проверяй относительные ссылки, существование путей и соответствие команд manifest/config/scripts. Для инструкций запуска различай сверку по коду и реально выполненный запуск.
- Документационные изменения не требуют продуктовых Unit/E2E. В итоговом сообщении укажи это явно.
